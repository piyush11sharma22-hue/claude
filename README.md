# Lead Research Assistant

A Claude Code skill that identifies high-quality leads for your product or service by analyzing your business, searching for target companies, and providing actionable contact strategies. Perfect for sales, business development, and marketing professionals.

## Installation

This repository ships the skill under `.claude/skills/lead-research-assistant/`. When Claude Code runs in this repository (or the skill directory is copied into your own project's `.claude/skills/`), the skill becomes available automatically.

## Usage

Describe your product/service and what you're looking for:

```
I'm building [product description]. Find me 10 companies in [location/industry]
that would be good leads for this.
```

Run it from your product's source directory for automatic context, or provide an explicit ideal customer profile for more targeted research.

See [`.claude/skills/lead-research-assistant/SKILL.md`](.claude/skills/lead-research-assistant/SKILL.md) for the full skill definition, usage patterns, and output format.
